# Expense List

A simple Java console application for recording and managing personal expenses.

## Features

- Add an expense
- Enter an expense name, amount, and category
- Display available expense categories
- Validate user-entered categories
- Handle invalid category input
- List saved expenses
- Calculate total expenses

## Technologies

- Java
- Java Streams
- Enums
- Maven
- JUnit

## Requirements

- JDK 17 or later
- IntelliJ IDEA or another Java IDE

## Run the project

1. Clone the repository:

   ```bash
   git clone https://github.com/DeveloperDurga/ExpenseTracker.git
   ```

2. Open the project in IntelliJ IDEA.

3. Run the `Main` class.

## Available categories

- FOOD
- TRANSPORT
- ENTERTAINMENT
- UTILITIES

## Example usage

```text
Available categories: [FOOD, TRANSPORT, ENTERTAINMENT, UTILITIES]
Enter your category: food
Expense added successfully.
```
